# Online Voting System (PHP + MySQL)

BCA 5th Semester Mini Project, 2026 - Bhawanipur Global Education

## How to run
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `C:\xampp\htdocs\` (or D:).
3. Copy `config.sample.php` to `config.php` and set `BASE_URL` to your folder name.
4. Open http://localhost/phpmyadmin, go to Import and import `database.sql`.
5. (Optional) import `sample_data.sql` to get one test election.
6. Open http://localhost/<folder-name>/index.php
